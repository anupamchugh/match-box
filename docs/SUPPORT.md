# Machiss support

Machiss is an early local macOS technical preview. Support requests should
include the app version, macOS version, and a description of the visible state
without attaching real dating profiles, screenshots, conversations, or account
details.

Do not send private conversation content or ScreenCaptureKit recordings in a
support request. Reproduce with the fictional fixtures in the repository when
possible. If capture fails, describe whether the issue occurred during reading,
review, or local saving; Machiss never sends messages or changes the dating
service.

Public launch still requires a signed/notarized build, a final privacy-policy
URL, and an owner-approved native capture test.
